# ZERO Launcher — Translations

Languages: **English** (source, default) and **Español** (neutral Spanish). Owner decision (Mission 004, B5): neutral Spanish
with **"tú"** (never "vos"/voseo, never "usted"): "Elige", "Haz clic", "Puedes", "Tu instancia".

## How it works (summary; details in ARCHITECTURE.md "Languages")
- ZERO's own translation file `zero_es.ts` lives in the source tree and is compiled into the app (qrc). It covers ZERO's strings and the
  upstream strings ZERO changed. Prism's own Spanish translation (downloaded by Prism's TranslationsModel, as upstream does) covers
  the remaining upstream screens; ZERO's translator is installed last, so ZERO's text wins.
- Unfinished entries are not compiled: an untranslated string shows in English (or Prism's Spanish), never as an empty label.

## Style rules
- Short, plain, friendly; same tone as the English UI. Sentence case (only the first word capitalised), as in English.
- Keep placeholders exactly (`%1`, `%2`, `%n`, `&` mnemonics, HTML tags, `\n`). Keep keyboard names (Ctrl, Alt, Enter).
- Keep product and brand names: ZERO, Minecraft, Modrinth, CurseForge, Technic, ATLauncher, FTB, Fabric, Quilt, Forge, NeoForge,
  OptiFine, Iris, Sodium, Java, OneDrive, Google Drive, Dropbox, Discord, Microsoft, Ely.by.
- Units: "MB", "GB", "min", "h", "s" unchanged. Numbers and dates come from the locale.
- Buttons are verbs in infinitive form: "Instalar", "Actualizar", "Deshacer", "Cancelar", "Guardar", "Eliminar".
- Toasts and captions: full sentences without a final period when the English has none.

## How to update the catalogue
1. Change the English text in the code with `tr("...")` (or `QCoreApplication::translate("<Context>", "...")` in a file without a class; see
   ARCHITECTURE.md "Languages" for the rules).
2. Run `scripts/zero/i18n-update.sh` (Git Bash, repo root). It runs `lupdate` over `launcher/` and updates
   `launcher/resources/zero/i18n/zero_es.ts`: new strings are added as `type="unfinished"`, strings that no longer exist are dropped, every
   translation that still matches is kept. It prints how many messages are finished and unfinished (`Zero::` contexts and the rest) and
   warns about ZERO classes that lupdate cannot attribute (a class that uses `tr()` without `Q_OBJECT`).
3. Translate: fill the `<translation>` of the entry **and remove `type="unfinished"`** from it (Qt Linguist does it when you mark the entry
   done; by hand the attribute is deleted). An entry that is still unfinished is not compiled: it shows in English. Keep `%1`, `%n`, `&`,
   HTML tags and `\n` exactly. Plurals (`numerus="yes"`) have two forms in Spanish: `one` and `other`.
4. Build. `lrelease -nounfinished` makes `zero_es.qm` and embeds it in the app. Start the launcher with Language = Español to look at it.

Notes
- `lupdate` is `C:\msys64\ucrt64\qt6-static\bin\lupdate.exe` here (the one in `ucrt64\bin` needs `Qt6Qml.dll`, which is not installed).
- The `.ts` has no file names or line numbers (`-locations none`) and no absolute paths, so it only changes when texts change.
- The same English text in two contexts is two entries: translate each (the update script turns the same-text and similar-text merge
  heuristics off, so nothing is filled in by guess).
- What Prism's own Spanish covers (the screens ZERO did not touch) is not in this file; ZERO's entries win where both exist.
