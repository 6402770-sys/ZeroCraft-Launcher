# File map (ZERO-specific + key upstream entry points)

- `CLAUDE.md` — agent rules and commands (keep short)
- `HANDOFF.md` — current status, verified state, QA checklist, next tasks
- `docs/zero/MISSION.md` — owner product brief (binding requirements and priorities)
- `docs/zero/DESIGN.md` — Obsidian design system spec (tokens, components)
- `docs/zero/SHELL.md` — main window / Home / Library spec, dev screenshot flags
- `docs/zero/ARCHITECTURE.md` — layering and key decisions
- `docs/zero/CREDENTIALS.md` — external services/keys and release requirements
- `docs/zero/THIRD_PARTY.md` — Lucide icons attribution
- `scripts/zero/build.sh` — configure/build/test/run (MSYS2 UCRT64)
- `scripts/zero/run-dev.cmd` — double-click launcher for the dev build (adds MSYS2 DLLs to PATH)
- `CMakeLists.txt` — version, service URLs/keys, `ZERO_RELEASE_BUILD` guard
- `program_info/` — branding: names/AppID (`CMakeLists.txt`), icons (`zero-logo.svg` master, `zerolauncher.ico`), `.rc`, NSIS installer
- `launcher/Application.cpp` — startup, data dir, CLI flags (`--zero-screenshot`), settings registration, Prism import (`handleDataMigration`)
- `launcher/ui/MainWindow.*` — controller: actions, selection, launch/kill; builds `ZeroShell`
- `launcher/ui/zero/` — design system: `ZeroTokens.h`, `ZeroThemeState` (runtime ThemeSpec), `ZeroStyle` (QSS/palette/fonts), `ZeroTheme` (ITheme, popup filter, dark title bar), `ZeroIcons`, `ZeroMotion` (tokens/easing, motion setting resolution, `StateAnimator`), `ZeroTransition` (snapshot overlays: crossfade / rise / pixel dissolve), `ZeroRipple` (press ripple filter), `ZeroFormat` (relative time/playtime), components (`ZeroCard`, `ZeroNavRail`, `ZeroPageHeader`, `ZeroEmptyState`, `ZeroToast`, `ZeroSpinner`), `ZeroGallery` (dev gallery)
- `launcher/ui/zero/ZeroPaint.*` — theme-aware painting: `panelPath` (rounded/notched), `paintBevel`, `paintBackground` (stone texture)
- `launcher/ui/zero/ZeroPixelFont.*` — original 5x7 "ZERO Pixel" font generated as TrueType in memory, `registerPixelFont()`
- `launcher/ui/zero/ZeroPlayButton.*` — the signature Play button: custom-painted, driven by `Application::launchPhaseChanged/launchEnded` (Idle / Preparing / Running / Failed)
- `launcher/ui/zero/pages/AppearancePage.*` — Appearance page: theme cards + live `ThemePreview` (painted from a ThemeSpec), Apply theme, motion setting
- `launcher/ui/zero/shell/` — `ZeroShell` (rail + top bar + page stack, Alt+N page shortcuts), `ShellPage` (page chrome API: title/subtitle/breadcrumb/top bar actions), `ZeroTopBar` (+ `ChromeTitle`), `AccountChip` (compact chip in the top bar)
- `launcher/ui/zero/palette/` — command palette (Ctrl+K) and shortcut sheet (Ctrl+/): `PaletteOverlay` (shared overlay: backdrop, panel, open/close animation, focus restore), `ZeroCommandPalette` (+ `PaletteResults`), `ZeroShortcutSheet`, `PaletteTypes.h` (`PaletteCommand`, `ShortcutGroup` descriptors MainWindow fills), `PaletteDraw` (key caps)
- `launcher/ui/zero/pages/` — `HomePage`, `LibraryPage`, `InstanceDetailsPanel`, `ZeroInstanceDelegate` (grid cards), `InstanceTableModel` (list view), `InstanceInfo` (version/loader read-only), `IconTile`, `ElidedLabel`
- `launcher/zero/` — non-UI ZERO services (diagnostics/Crash Detective, …)
- `launcher/zero/profiles/` — instance profiles: `InstanceProfile` (favorite, tags, description = `notes`, artwork file, mod count, `Notifier`) and `LibraryFilter` (filter chips + search, pure logic)
- `launcher/zero/worlds/` — Worlds Hub scanner: `WorldScanner` (read-only `scanWorldsDir`, `folderSize`, sort / search, async scanner with generations; no widgets)
- `launcher/zero/storage/` — Storage Manager core: `StorageScanner` (per-category / per-instance disk usage, old log / crash report cleanup candidates, restore leftovers, validated Recycle Bin trash, async scanner; no widgets)
- `launcher/zero/backup/` — Smart Backup: `WorldBackup` (create / verify / list / restore / retention / delete of world backups; no widgets), `WorldBackupJobs` (app-level runner: one job per world on the pool, launch lock), `AutoBackup` (automatic backups of the played worlds after a session)
- `launcher/ui/zero/pages/` (Worlds Hub) — `WorldsPage` (toolbar, list, empty states), `WorldRows` (`WorldRowModel` + painted `WorldRowDelegate`), `WorldDetailsPanel`, `WorldBackupsSection` (Backups block of the details panel), `WorldIcon` (pixel-crisp world icon tiles)
- `launcher/zero/history/` — session history: `SessionHistory` (one record per launch, classification, JSON store, recorder slots; no widgets)
- `launcher/ui/zero/pages/` (Library 2.0) — `FilterChipBar` (scrollable single-select chips), `ArtworkCache` (`Artwork::cover`, `ArtworkView`), `FlowLayout` (wrapping layout for tags)
- `launcher/zero/palette/CommandMatcher.*` — pure ranking logic of the palette (fuzzy score, aliases, recency, tie-breaks, highlight positions)
- `launcher/resources/zero/` — `obsidian.qss` (base, token placeholders), `minecraft.qss` (per-theme overlay appended to the base), `zero.qrc`, `icons/` (Lucide SVGs + LICENSE)
- `launcher/ui/themes/ThemeManager.cpp` — registers the ZERO themes (`zero-obsidian`, `zero-minecraft`) first, defaults
- `launcher/ui/instanceview/` — upstream grid view (ZERO metrics, group headers, text filter in `InstanceProxyModel`)
- `tests/ZeroTheme_test.cpp`, `tests/ZeroPixelFont_test.cpp` — theme engine v2 (specs, contrast, panel shapes, texture) and pixel font tests
- `tests/ZeroPlayButton_test.cpp` — Play button state machine (cycle, failure, abort, crash, ignored clicks, stop request)
- `tests/ZeroMotion_test.cpp` — motion system: setting resolution + legacy migration, overlays (self-deleting, replaceable, nothing with motion off), ripple, toasts
- `tests/ZeroShell_test.cpp` — shell/top bar chrome swap, breadcrumb, Alt+N shortcuts
- `tests/InstanceProfile_test.cpp`, `tests/LibraryFilter_test.cpp`, `tests/ZeroLibrary_test.cpp` — profile data (tags, artwork atomic write, mod count), filter chips, chip bar / flow layout / artwork crop / card star click
- `tests/WorldBackup_test.cpp` — Smart Backup: round trip, verify, zip-slip, restore + failure paths, retention (manual / safety / auto), listing, free space, job runner / launch lock
- `tests/AutoBackup_test.cpp` — automatic backups: world selection (mtime, slack, size cap) and the service queue with real temp worlds
- `tests/StorageScanner_test.cpp` — storage report math (no double counting, junctions, nested / duplicate dirs), cleanup detection, trash validation + failure paths, async scanner
- `tests/WorldScanner_test.cpp` — world scan of real folder layouts, skipped entries, read-only guarantee, folder size (links / junctions), search / sort, scanner generations
- `tests/SessionHistory_test.cpp` — launch classification, recorder sequences with injected clock, persistence, cap, corrupt / malformed files
- `tests/CommandMatcher_test.cpp`, `tests/ZeroCommandPalette_test.cpp` — palette ranking; palette/sheet open, close, navigation, callbacks, focus
- `tests/Zero*_test.cpp`, `tests/CrashDetective_test.cpp` — ZERO unit tests (in `LauncherTests`, listed in `tests/CMakeLists.txt`)
